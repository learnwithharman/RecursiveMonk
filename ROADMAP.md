# RecursiveMonk — Multiplayer UNO

A simple, clean multiplayer UNO game in the browser. Real-time, no accounts, just create a room and play.

---

## ✅ Done

- [x] Node.js + Socket.IO server setup
- [x] Room creation with 6-character codes
- [x] Join room + lobby UI with player list & host badges
- [x] Full 108-card UNO deck generation
- [x] Deal 7 cards, determine starting top card
- [x] Player hand display (private, client-side)
- [x] Core turn rotation (clockwise / counter-clockwise)
- [x] Card validation (match color, number, or wild)
- [x] Draw from deck, auto-pass if no playable card drawn
- [x] Skip, Reverse, Draw Two action effects
- [x] Wild card color selection modal
- [x] Wild Draw Four logic
- [x] UNO! call & penalty challenge system
- [x] Scrollable game activity log
- [x] Direction indicator (↻ / ↺)
- [x] Reconnect / rejoin via localStorage session
- [x] Mid-game disconnect handling (30s grace period)
- [x] Web Audio sound effects (play, draw, UNO!, error)
- [x] Quick emote reactions with floating animations
